# Lumi v1.0.0 — Public MLX Release

Lumi is a 29,398,016-parameter story-continuation model built and pretrained from scratch using Apple's MLX framework. This release makes the original October 19, 2026 model downloadable with its matching tokenizer, standalone inference code, MIT license, model card, and training-data attribution.

## Download and run

Download **`lumi-v1.0.0-mlx.tar.gz`** and **`lumi-v1.0.0-mlx.tar.gz.sha256`** from this release's assets. GitHub's automatically generated source archives do not contain model weights.

```sh
shasum -a 256 -c lumi-v1.0.0-mlx.tar.gz.sha256
tar -xzf lumi-v1.0.0-mlx.tar.gz
cd lumi-v1-mlx
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python inference.py --prompt "Once upon a time, there was a little girl named Lily." --max-tokens 200 --temperature 1.0 --seed 42
```

Requires **macOS on Apple Silicon and Python 3.12**. This is a native MLX package. See the [repository's compatibility experiment](https://github.com/pxcd/project-lumi/tree/main/experiments/lmstudio-compat) for LM Studio conversion.

## Model and license

- 8 Transformer layers, width 512, 8 attention heads, feed-forward width 2,048.
- Vocabulary of 8,192 tokens; context window of 512 tokens; float32 weights.
- Original run record: 11,000 steps, trained on a sampled TinyStories subset.
- MIT for Lumi's code and trained weights. TinyStories and dependencies retain their own licenses.
- Story continuation only; not instruction-tuned. Repetition, story restarts, inconsistent characters, and nonsensical text are known limitations.
- v1.0 has no EOS token and generates until the requested token limit. Keep its weights and tokenizer together; the later v1.1 tokenizer is incompatible.

## Integrity and verification

The original model files and local historical archive were preserved. The public archive adds licensing and documentation without changing the model, tokenizer, inference code, or configuration. The existing `v1.0.0` Git tag remains at its original commit; public documentation and packaging records are on `main`.

The public archive was extracted and checked, then used for a fresh 200-token inference run in the existing project environment. The seed-42 output matched the preserved first-generation record. Five smoke checks and six v1.1 tests also passed. A clean dependency installation was not tested.
